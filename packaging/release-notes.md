## 净页 / ScanCleaner

本次更新启用版本标签触发的自动构建和发布。

本地处理扫描 PDF 和图片，支持去底色、黑白增强、锐化及处理前后对照预览。支持将当前 PDF 页面导出为 PNG/JPG，或将处理后的图片导出成单页 PDF。

- Windows 10（1809+）和 Windows 11 请下载 `windows-10-11-x64`。
- Windows 7 SP1、Windows 8/8.1 的 `windows-7-8-x64-experimental` 为实验构建。已在新版 Windows 的构建环境完成测试，旧系统运行情况仍待验证。
- macOS 可按芯片选择 `x86_64` 或 `arm64`，`universal` 同时包含两种架构。
- Linux 请选择对应 Ubuntu 24.04、Debian 13 或 Arch Linux 的包。

`SHA256SUMS.txt` 提供文件校验值。项目源码使用 MIT 协议，包内第三方许可详见所附声明。
